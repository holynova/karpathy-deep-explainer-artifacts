Paradigm Demonstration

Karpathy 输出演进互动体验器

亲身体验同一个概念（例如“分布式令牌桶限流算法”）在不同输出抽象层级下的认知效率差异。

常规 LLM 冗长回答： 令牌桶算法是一个非常经典的流量控制算法。它的基本思想是系统会以一个恒定的速度往桶里面放令牌，当桶满了的时候多出来的令牌就会被丢弃掉。当有请求来的时候，请求必须要从桶里面拿走一个或者多个令牌才能继续被处理，如果桶里面没有足够的令牌了，那么这个请求可能就会被拒绝或者进入等待队列。这个算法的优点是可以允许一定程度的突发流量，因为如果一段时间没有请求，桶里的令牌会积攒到最大容量，后续瞬间来的一批请求可以一次性消费这些令牌快速通过，之后再按照恒定速率处理……
认知负荷：高。文字冗长，读者需要在脑中建立心理模型并推演数学边界。
受控规范文本 (ASD-STE100 Specification):
// RULE: Maximum 20 words per sentence. Use only approved verbs.

1. The system puts tokens into the bucket at a constant rate \(r\).

2. The bucket holds a maximum number of tokens \(C\).

3. Each incoming request takes 1 token.

4. If tokens are available: Accept the request and decrement token count.

5. If no tokens are available: Reject the request immediately (HTTP 429).

6. Result: Allows bursts up to capacity \(C\). Limits average throughput to rate \(r\).

认知负荷：极低。零废话、零修饰，逻辑状态转换毫无歧义。
